# MO Med Pharmacy website

A simple, fast, mobile-friendly static website designed to run on GitHub Pages with a GoDaddy domain.

## Before publishing

Update these placeholders in `index.html`:
- Phone number
- WhatsApp number
- Email address
- Physical address
- Opening hours
- Services/about text

## Publishing

1. Create a GitHub repository, e.g. `momed-pharmacy`.
2. Upload `index.html`, `style.css` and `script.js` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Add your GoDaddy domain under the GitHub Pages **Custom domain** setting.
6. In GoDaddy DNS, point the domain to the GitHub Pages DNS records shown by GitHub.
7. Wait for DNS propagation, then enable HTTPS in GitHub Pages.

## Important

The website intentionally uses placeholders rather than inventing MO Med Pharmacy's actual contact details or trading hours.
